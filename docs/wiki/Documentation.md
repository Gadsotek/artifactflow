# Documentation

The main repository is the source of truth. These pages are short entry points.

## Finding and continuing your work

Home brings together recently opened pages, favorites, and workspace activity.
The workspace overview puts search above your personal page lists. Use the
workspace panel's filter to find a workspace; indentation shows its parent levels.
Use **Recently opened** for your last 100 page visits or **Favorites** for up to
200 saved references. These lists are private, reflect current page names, and
grant no additional access. Clearing recent history keeps favorites. Archived
pages leave recents and quick search; accessible archived favorites stay labeled.
If inaccessible favorites fill the limit, adding another favorite releases those
unavailable references. Visits and favorites do not create content versions or
change the page's shared activity or update time.

Open **Search or jump to** with its button or Cmd/Ctrl+K. Type part of a title,
choose all accessible workspaces or one exact workspace, and use the arrow keys
and Enter to open a result. Escape closes search. Search is limited to authorized
page metadata; use the **Library** to search full content. The Library shows 25
results at a time, keeps filters across pages, and offers additional filters
under **More filters**. Remove an active filter with its chip to restart at the
first page while keeping the other filters. A selected parent workspace does not
include descendants.

**New page** starts a separate page. **Add child page** explicitly preselects the
current page as its parent. Page breadcrumbs and child links provide local
navigation; editing, sharing, and versions stay prominent, with less frequent
tools under **More**. Sharing offers internal links, access settings, and external
link options; opening the dialog creates no external link.

Text editors warn before leaving unsaved changes. **Copy draft** and **Open
current version** support recovery after a conflict; saving still creates a new
version and refuses stale updates. There is no background draft persistence or
automatic merge. **AI connections** explains token permissions and provides
configuration copy controls; password and authenticator checks remain required.
