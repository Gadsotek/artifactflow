# Roadmap

ArtifactFlow is a public alpha. Direction is not a release promise.

| Status | Scope |
| --- | --- |
| Available | Markdown/Mermaid, single-file HTML, normalized PNG/JPEG, search, versions, source diffs, scoped MCP |
| Available | Page hierarchy, optional declared provenance, TOTP and recovery |
| Released v0.0.7 | Narrow expiring and one-time external page links |
| Released v0.0.9 | Three-level nested shared workspaces |
| Implemented, default-off | Native-text PDF, typed XLSX, searchable DOCX through isolated processors |
| Later candidates | PDF OCR, provenance entry/amendment, reference redaction/retention, provider attestations |

DOCX also requires the PDF processor. Enabling document formats requires the
running deployment's containment, resource, browser, and release checks.

Simultaneous editing, a visual diff UI, automatic chat import, agent execution,
vector search, public marketplaces, and arbitrary multi-file uploads are not
promised. The [canonical roadmap](https://github.com/Gadsotek/artifactflow/blob/main/ROADMAP.md)
and [changelog](https://github.com/Gadsotek/artifactflow/blob/main/CHANGELOG.md)
carry current detail and release history.
