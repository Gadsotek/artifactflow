# ArtifactFlow

**Keep AI-generated work useful beyond the chat.**

ArtifactFlow is an open-source, self-hosted workspace for AI-generated artifacts.
Save, find, use, and share useful reports, calculators, dashboards, and documents.
Colleagues work in the browser without Git or development tools; authorized MCP
clients can retrieve the same artifacts and continue the work across AI tools.

It preserves deliberate outputs, not conversations. There is no automatic
chat capture, built-in AI generation, or required model subscription.
