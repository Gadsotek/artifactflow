How it works

Good work deserves
a next chapter.

A product manager turns an AI-generated calculator into a tool colleagues and external stakeholders can use.

Try it locally ↗
  1. 01

    Generate

    Start with a useful result.

    A PM asks an AI tool for a self-contained interactive HTML report or calculator.

  2. 02

    Save

    Give it a shared home.

    Paste or upload the output. Choose a workspace and tags.

    One artifact, a stable identity, an owner.
  3. 03

    Use together

    Put it within reach.

    Authorized colleagues find and use the isolated preview in their browser. No repository clone, local code setup, or publishing pipeline.

  4. 04

    Share externally

    Choose the access pattern.

    With administrator enablement and sharing permission, the PM sends a stakeholder an expiring link for multiple sessions or a one-time link for one successful redemption.

    One-time has no time expiry; its established session continues while authorized. Both modes are revocable. Delivery and identity limits →
  5. 05

    Revise

    Keep the same artifact.

    Save the revised report as a new version. Valid external shares follow its current version.

    Inspect or restore history within retention limits.
  6. 06

    Continue with AI

    Build on the saved work.

    An authorized MCP-compatible client retrieves the source and saves another revision within its scopes. Stale writes are rejected.

Useful details

Clear history.
Honest context.

Content and metadata differ.

Content appends versions. Titles, tags, and descriptions have a separate metadata revision. Source diffs exist; a visual diff UI does not yet.

Record what you know.

Optional provider and model claims remain partial and self-reported.

Keep the momentum

Different tools. Shared progress.

ArtifactFlow stores the work. It does not run agents or provide simultaneous editing.
